# Chord Code Pro: material para vídeo

Pasta só de mídia e documentação de marketing do **Chord Code Pro** (o código do plugin fica em outro repositório, privado). Está aqui porque este repositório é público, então os links diretos das imagens e áudios abrem em qualquer ferramenta de vídeo.

- [produto.md](produto.md): o que é, oferta, números, controles, frases prontas.
- [identidade-visual.md](identidade-visual.md): cores, fontes, logo, movimento, regras.
- [roteiro.md](roteiro.md): roteiro cena por cena do vídeo "1 clique. 4 acordes."
- [prompt-video.txt](prompt-video.txt): prompt para colar na ferramenta de vídeo.
- [prompt-video-com-repo.txt](prompt-video-com-repo.txt): o mesmo prompt com os links diretos de cada arquivo.
- [briefing-completo.md](briefing-completo.md): briefing visual e funcional completo (os caminhos de imagem dele apontam para a pasta de arquivos do projeto, não para esta pasta).
- `img/`: telas reais do plugin, recortes (cards, GERAR, controles, ARRASTAR MIDI...), seletor, caixa 3D, ícone, logos, paleta.
- `audio/`: `progressao-som-real.mp3` (som real do plugin, Fmaj7 · G · Em7 · Am9) e `timbres/` (os 7 timbres de prévia).
