# Chord Code Pro: identidade visual

**Dark premium com calor laranja.** Fundo quase preto, superfícies grafite, e o laranja aparece como *luz*: glow atrás do logo, luz subindo por trás dos cards, glow no GERAR e no card que está tocando. Sem neon, sem cores frias. Paleta completa: [img/paleta.png](img/paleta.png).

## Cores
| Uso | Hex |
|---|---|
| Fundo | `#07080A` (landing/anúncios `#050606`) |
| Cards | `#0D0F12` → `#15181D` |
| Borda | `#272B32` |
| Laranja (marca) | `#FF5A0A` |
| Laranja claro | `#FF8C3A` |
| Âmbar | `#FFB23D` |
| Gradiente de acento | `#FF5A0A → #FFB23D` |
| Texto | `#F5F6F8` / secundário `#8B929C` |

## Fontes
- Plugin: **Inter** (rótulos em CAIXA ALTA, Bold, tracking largo).
- Títulos de marketing: **Space Grotesk** Bold. Texto: **Manrope** ou Inter.
- Títulos em duas partes: primeira branca, segunda **laranja** ("Gostou? / **Trava.**").

## Logo
Ícone quadrado arredondado laranja com barras de waveform escuras ([img/icone-chord-code.png](img/icone-chord-code.png)). Wordmark "CHORD" branco + "CODE" laranja ([img/logo-chord-code.png](img/logo-chord-code.png)). Assinatura AUDIO MAKERS.

## Movimento
- Easing suave tipo ease-out, sem bounce.
- **Card tocando**: borda laranja com glow, luz subindo da base, 9 barras em gradiente âmbar/laranja pulsando. O destaque "caminha" de card em card ([img/cards-tocando.gif](img/cards-tocando.gif)).
- **GERAR**: sempre com glow; no clique os nomes dos acordes trocam (bom ponto de corte/whoosh).
- Modais abrem sobre a interface desfocada e escurecida.

## Regras que não mudam
- Interface **sempre real** (as imagens daqui), nunca redesenhada.
- Laranja só como luz e destaque. Se tudo for laranja, nada se destaca.
- Preço vigente **R$37** (alguns anúncios antigos mostram R$47, não usar).
- Evitar close na pílula de versão do cabeçalho.
